# 🧘‍♂️ Meditation App UI – Jetpack Compose

This repository contains the **user interface (UI)** of a **Meditation App**, built entirely using **Jetpack Compose**. It features a **clean, modern, and minimalist** design aimed at delivering a **calm and intuitive user experience**.

This is a **UI clone/demo**, focused on layout and design — no backend or audio functionality is included.

---

## 🌟 Features

- 100% Jetpack Compose – No XML at all
- Beautiful **soothing dark/light theme**
- Clean typography and soft color palette
- Home screen with:
  - Greeting header
  - Daily meditation sessions
  - Category chips (Relax, Focus, Sleep, etc.)
  - Featured meditation card
- Responsive, adaptive layouts
- Scrollable lists using `LazyRow` and `LazyColumn`
- Modular & reusable Composables
